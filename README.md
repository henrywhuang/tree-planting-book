# 两端植树 · 1号的数学立体书

[打开立体书](https://henrywhuang.github.io/tree-planting-book/)

以用户提供的互动立体书为参考，重新实现学习状态、页面交互、练习验证、语音调度和进度保存。保留封面、剪纸角色、音频、程序化纸景及儿歌分镜，拆分为独立的本地资源和可读的渲染模块。

这是可直接托管在 GitHub Pages 的静态网页，不需要服务端或原平台接口。Three.js 及音频、字体、插画都随仓库提供，不依赖外部 CDN。学习进度保存在当前浏览器，不会上传。

## 学习流程

1. 打开立体书，在小路两端各种一棵树。
2. 点击发光的小路，跟着1号走过一个间隔。
3. 分别种3、4棵树，先选择段数，再由角色走路数段进行验证。选错可以再次选择。
4. 对照「2、3、4棵 / 1、2、3段」记录，发现「段数＝棵数－1」。
5. 完成5、6、7棵树练习：先猜段数，再自动种树、数段、核对答案。
6. 播放原儿歌及14个动画分镜，显示逐句歌词。支持暂停、继续、提前结束与自然结束后的合书。

配套功能：声音和字幕开关、按章节解锁的书签、当前题重做、从头开始、完成反馈、三种庆祝动画、数字鼠标轨迹、键盘操作、手机与横屏布局、刷新续学、损坏/禁用存储的恢复处理。

完成一组后会自动继续，也可点击右下角「继续」或按 `→`。从书签回看已学章节时会保留在当前页；继续操作后恢复学习流程。按 `Esc` 关闭书签。首次播放音频需要点击书本或播放按钮。

## 本地运行

Node.js 20或以上：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:4173`）。也可用任意静态 HTTP 服务器运行仓库根目录。浏览器需要支持 ES Modules、WebGL 2、FontFace 和 HTML Audio；请通过 HTTP/HTTPS 打开。

```sh
npm run check  # 语法、模块引用和资源路径
npm test       # 完整学习路径、错题重试、存储恢复与重置
npm run build  # 输出独立静态站到 dist/
```

## 项目结构

| 文件                | 用途                                             |
| ------------------- | ------------------------------------------------ |
| `src/app.js`        | 学习流程、用户操作、动画调度、章节导航           |
| `src/progress.js`   | 纯状态逻辑、答题判断、进度校验及浏览器持久化     |
| `src/book-scene.js` | 教学场景、种树光圈、间隔色带、书页内容           |
| `src/view.js`       | 可访问的交互热点、工具栏、字幕气泡、数字轨迹     |
| `src/audio.js`      | 配音、钢琴、儿歌、Web Audio 音效                 |
| `src/content.js`    | 本地资源地址、配音文本、儿歌分镜数据             |
| `src/render/`       | 书桌与书本、角色骨架、纸景、步态、庆祝与儿歌导演 |
| `assets/`           | 字体、插画和音频                                 |
| `vendor/`           | 固定版本的 Three.js r181 及许可                  |
| `tests/`            | 状态和恢复逻辑回归测试                           |

所有资源路径均相对当前模块解析，支持 GitHub Pages 的项目子目录。进度使用专有键 `tree-planting-book:progress:v1`，不会覆盖同一域名下其他项目的存储。

## 发布

当前仓库的 GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 让静态文件直接提供服务。修改并推送 `main` 后，GitHub 会重新发布。

迁移到其他仓库时，在仓库 Settings → Pages 中选择 Deploy from a branch → `main` → `/ (root)`；也可以把 `dist/` 发布到任意静态托管。
